# 《好孩子》小程序 · 产品设计文档 v1.1

> 项目名：好孩子（good-kid）
> 首版范围：语文（随机生字默写 + 随机练习）、数学（随机口算）、英语（随机单词默写）
> 产品定位：**轻量日频练习工具**——不跟大厂卷功能，"每天几分钟、积少成多、重复记忆"
> 目标用户：小学生家长（操作者）+ 孩子（使用者），首发聚焦三年级
> 变更记录：v1.1 明确轻量化定位与乐趣机制；口算降级为完整性拼图；断点续听挪 V2

## 一、产品概述

### 解决什么问题

1. **家长的苦役**：每晚听写/口算练习需要家长出题、念题、盯写、批改、记错题，全程 15–30 分钟
2. **出题麻烦**：家长自己编口算题、挑生字，质量随机且费时
3. **错题无沉淀**：练错了就过了，缺少系统性复习闭环
4. **整块时间难凑**：孩子注意力有限、家长时间零碎，缺一个"排队等餐也能来一轮"的微练习工具

### 核心价值主张

- **微练习**：每次 10 题封顶、3 分钟完成，零心理防御成本
- **随机出题**：三科题库自动生成，家长零投入、零学习成本
- **自动播报**：TTS 报词，家长不用念题
- **错题闭环**：错题自动沉淀 → 次日优先重现 → 重练消灭，"软件记得我孩子哪题错过"
- **积少成多**：每日 10 分钟 × 3 科 ≈ 一个月约 900 题的重复记忆量，周报让积累可见
- 老师真实考点资料驱动的词库（内容壁垒，竞品普遍存在数据校对痛点）

### 竞争策略（不卷大厂）

- 语文/英语听写：竞品均为一人/小团队，无巨头垄断，是主攻方向
- 数学口算：**降级为三科闭环的完整性拼图**——不做拍照批改、不追 PDF 打印，避开出题宝/小猿口算/作业帮的火力区
- 差异化主轴：**三科统一错题闭环**（竞品全是单科闭环）+ 考点词库准确性

## 二、信息架构：三级导航

```
L1 学科选择（首页）
 ├── 语文 → L2 年级（首次弹选择，之后记忆）→ L3 练习样式
 │          · 生字默写（随机混抽 / 按单元）
 │          · 随机练习（看拼音选字）
 ├── 数学 → L2 年级 → L3 练习样式
 │          · 随机口算（混合运算）
 │          · 专项练习（纯加 / 纯减 / 纯乘 / 纯除）
 │          · 60 秒限时挑战
 └── 英语 → L2 年级 → L3 练习样式
            · 单词默写（听音写英文）
            · 看中文写英文

全局入口：错题本（跨科汇总，可按科筛选）、周报、设置
```

### 年级记忆规则

- 年级选择**按科独立记忆**：语文三年级、数学一年级可以并存（各科进度不同步场景）
- 首次进入某科 → 半屏弹层选年级，选完即用
- 之后进入 → 默认上次年级，随时可改
- 修改入口两处：① 该科页面顶部"三年级 ⌄"点击重选（高频） ② 我的-设置-学习年级（兜底）
- 年级切换后错题本数据保留（按科+年级筛选展示）

### L3 练习样式统一交互骨架

所有样式共享三段式，参数页与结果页全样式复用：

1. **参数页（全部默认好，做到"打开就能练"）**：题量默认 10、报词语速默认中档、错题加权默认开；高级选项折叠
2. **练习页**：按样式渲染（默写 = 报词卡片流 / 口算 = 键盘答题 / 选择 = 四选一）
3. **结果页**：对答案勾错（默写类）或即时判题汇总（口算选择类）→ 写错题本 → 分享卡片

### 微练习规则（轻量化核心）

- **单次 10 题封顶**，3 分钟内完成；不做 30 分钟的"作业级"练习
- **错题 3 题起步**：新用户哪怕只有 3 道错题，次日打开也优先重现——"惊喜时刻"提前到第二天
- **进入即出题**：零配置，所有参数有默认值
- **家长只勾错**：对答案 30 秒结束战斗；需要家长学习操作的功能一律不做
- **弱网可用**：兜底词库离线出题

## 三、乐趣与激励机制（轻量游戏化）

**总原则：只涨不掉的正反馈。** 断签不惩罚、无排行榜不攀比、单次不超 5 分钟。教育场景的游戏化翻车多因惩罚机制引发挫败放弃。

| 机制 | 说明 | 实现落点 |
|---|---|---|
| 连对星星 | 连对 5 题亮一排小星星，瞬时反馈 | 前端动效（Skyline worklet） |
| 火焰天数 | 连续练习天数展示；**断签不清零不惩罚**（断一天即放弃是签到产品经典死法） | db_quiz_log 聚合 |
| 满分奖杯 + 分享卡片 | 满分特殊动效；分享卡片文案值得反复 A/B——它是增长命脉 | 结果页 + Canvas |
| 难度自适应 | 连对 3 题偷偷升难度，连错 2 题降难度，孩子永远在"够得着"的区间（防挫败核心） | genQuiz 出题参数 |
| 错题清零进度条 | "错题从 47 个变 12 个"的下降曲线，比虚拽数字更让家长觉得值 | db_wrong_book 计数 |
| 段位闯关（V2 可选） | 只涨不掉的关卡进度 | — |

**不做**：排行榜（攀比压力对小学生弊大于利，且省掉社交合规与 UGC 审核）、对战 PK、复杂道具商城。

各科落点：
- 语文默写：报词间隔自动适配（连续跟得上稍加快）+ 报完星星动画
- 口算：连对星星 + 难度自适应即全部游戏化；60 秒挑战成绩只和自己比
- 英语：错题清零进度条（背单词"待消灭清单"心智天然契合）
- 三科周报共享："本周消灭 23 道错题"

## 四、首版功能详细设计

### 1. 语文 · 生字默写

选册/单元（或随机混抽）→ TTS 逐字报（间隔默认 8 秒可调，可重听）→ 家长对答案（卡片逐张翻转，勾错）→ 错题入库

- 多音字用组词消歧播报（"长——长短的长"）
- 随机混抽默认开启错题加权：错过的字更高概率重现（可在参数页关闭）
- 默写页防误触：报词中禁止返回，退出需二次确认
- ~~断点续听~~（挪 V2：价值密度低、状态同步边界多；V1 简化为"中途退出=作废重开"）

### 2. 语文 · 随机练习

V1 做"看拼音选字"单题型：屏幕出示拼音，四选一。题干可配 TTS 朗读。
（V2 扩展：拼音连线、组词填空）

### 3. 数学 · 随机口算

- 定位为**三科闭环的完整性拼图**：让用听写的家长顺口算省事，不做获客主力
- 不做：拍照批改、PDF 打印、错题原因 AI 分析——这些是大厂火力区
- 题型按年级参数化：三年级 = 万以内加减 + 表内乘除 + 简单混合运算
- 专项练习：可锁定单一运算（纯加/纯减/纯乘/纯除）
- 60 秒限时挑战：计时答题，成绩只和自己历史比，进周报
- 键盘输入即时判题，连对星星 + 难度自适应

### 4. 英语 · 单词默写

选单元 → TTS 读单词 → 家长勾错 → 错题本

- 两种模式：听音写英文 / 看中文写英文
- 错题清零进度条作为英语科的主激励
- V2 升级真人发音音频（云端 CDN 分发）

### 5. 错题本（跨科全局功能）

- 按科、年级筛选；错题含错误次数、最近错误时间
- **3 题起步即可练**：错题少也能生成重练卷
- 遗忘曲线逻辑：错 3 次后连对 2 次自动标记"已掌握"
- **错题重练**："再练一轮"生成错题卷（变现触点，见第六节）
- 清零进度条：各科错题数下降曲线

### 6. 周报

聚合一周三科数据：练习次数、正确率趋势、错题 TOP、"本周消灭错题数"、掌握进度、火焰天数。结果可生成分享卡片。

（原计划的"每晚 19:00 学习提醒"已砍掉：产品定位纯练习工具，且订阅消息平台规则只支持一次授权发一条，做不了每晚推送。V2 如需召回，再做"隔日召回"方案，见技术架构文档第五节。）

## 五、用户流程总览

```
打开小程序 → 首页选科 → （首次）选年级 → 选练习样式（默认即用）
→ 3 分钟微练习（报词/答题）→ 结果页（勾错/判题 + 星星/奖杯）
→ 错题入库 → 次日错题优先重现 → 周报看见积累 → 分享强化
```

## 六、变现与广告位设计

| 位置 | 形式 | 触发时机 |
|---|---|---|
| 错题重练 | 激励视频 | 自愿点击解锁"再练一轮"，每天首次免费 |
| 周报页底部 | Banner | 自然曝光 |
| 完成退出 | 插屏 | 结束练习返回首页，每人每天≤1 次 |

**原则：主流程（默写/练习/口算本身）永远无广告。** 广告只挂增值环节，家长为孩子的成绩自愿点击。

预期校准：竞品免费策略（听写小本子基础免费、班小二全免费）压制付费会员空间，**变现以广告为主**，会员制不作为近期目标。

## 七、合规与运营要点

- 不采集孩子个人信息，无实名注册（微信身份即用户身份）
- 首启展示用户协议 + 隐私政策弹窗
- 广告与宣传文案禁用"提分保证、必过"等绝对化用语
- 类目：首选「工具」（个人主体确定可选，也是个人虚拟支付开放类目）；教育类目个人主体开放度不稳，作为备选
- 冷启动路径：自家孩子班级群 → 分享卡片（孩子成绩+鼓励语）裂变 → 搜一搜关键词（听写、口算练习、看拼音写词语）→ 冲 500 UV 开流量主

## 八、开发与上线节奏（每天 2h + 周末）

| 阶段 | 交付 |
|---|---|
| W1 | 工程搭建 + 语文默写核心流程（本地词库版）——**此模块跑通即项目成功 70%** |
| W2 | 错题本 + 口算 + 英语默写 + 周报页 |
| W3 | 接入云开发（词库/错题上云）+ 广告位 |
| W4 | 备案提审 + 班级群冷启动 |

## 九、V2 扩展方向（已预留架构）

- 语文：拼音连线、组词填空、笔顺动画、断点续听
- 数学：竖式计算挑战
- 英语：真人发音音频、高频词分级表
- 全局：多孩档案切换、虚拟支付（去广告/打印不限次）、错题打印 A4 排版、段位闯关、隔日召回推送
