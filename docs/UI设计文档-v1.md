## 一、设计原则

| 原则 | 落地要求 |
|---|---|
| 打开即练 | 首屏主 CTA 一键直达练习；所有参数有默认值；首启用户 1 击进第一次练习 |
| 只涨不掉 | 星星/火焰/进度条全是正反馈；断签不清零；无惩罚、无攀比 UI |
| 家长 30 秒结束战斗 | 对答案是「卡片勾错」而非列表核对；需要家长学习操作的功能不做 |
| 主流程零广告 | 广告位只出现在错题重练（激励视频）、周报底部（Banner）、完成退出（插屏，≤1 次/天） |
| 主流一致性 | 导航层级、TabBar 结构、色彩语义向主流教育 App 看齐，降低学习成本 |

## 二、设计系统

### 色彩

| 用途 | 色值 | 说明 |
|---|---|---|
| 品牌主色 | `#534AB7`（紫） | 主 CTA 卡、选中态、品牌强调 |
| 主色浅底 | `#EEEDFE` | 选中 chip 背景、主按钮反白文字底 |
| 主色中间调 | `#7F77DD` / `#AFA9EC` | 柱状图梯度、次级强调 |
| 语文科 | 蓝 `#185FA5`（浅底 `#E6F1FB`） | 学科标识色 |
| 数学科 | 橙 `#854F0B`（浅底 `#FAEEDA`） | 连对计数、学科标识 |
| 英语科 | 绿 `#3B6D11`（浅底 `#EAF3DE`） | 学科标识 |
| 正确/掌握 | 绿 `#3B6D11` | 四选一选中正确、错题「待毕业」标签 |
| 错误/勾错 | 红 `#A32D2D` | 勾错描边、错误计数 |
| 火焰/激励 | 琥珀 `#FAC775` | 火焰天数、连对星星 |

规则：每屏主色唯一（紫），学科色只做学科标识，红绿只做对错语义，不混用。

### 布局与组件规格

- 白卡片圆角 12–16px + 浅灰页面底（`#F1EFE8` 级），无渐变无重阴影，0.5px 细描边
- 字号体系：大标题 15px/加粗、卡片标题 14px/加粗、正文 13px、辅助 12px、小注 11px、极小注 10px（仅日期）
- 数字键盘按键、四选一格等触控目标 ≥ 40×40px；主按钮高度 ≥ 44px
- 进度条统一 4–6px 细条，置于页面顶部导航之下
- 页面统一骨架：顶部导航（返回 ‹ + 标题/进度 + 上下文动作）→ 滚动内容区 → 底部固定主按钮
- chip 组件：圆角 8px、内边距 4×12px、选中态紫底白字、默认白底灰字细描边

## 三、信息架构与导航

### 页面流程总览

```
首启：打开 → 选年级（半屏弹层/顶部 chip）→ 主 CTA「开始第一次练习」→ 练习页
日常：打开 → 主 CTA「继续昨天的练习」→ 练习页 → 对答案 → 结果页（勾错/星星）
                                                      ↓
换科：首页三科卡 → 学科二级页（选样式 + 出题范围）→ 参数页（默认即用）→ 练习页
```

### TabBar（三项，周报已降级）

| Tab | 频率 | 内容 |
|---|---|---|
| 练习 | 日频 | 首页（主 CTA + 三科卡） |
| 错题本 | 日频 | 跨科错题列表、清零进度、再练一轮 |
| 我的 | 低频 | 周报入口、设置、关于 |

### 年级选择（全局默认 + 科目级覆盖）

1. 首页顶部一排年级 chip（一 ~ 六年级），选择后即时刷新下方科目卡
2. 英语卡按年级判断：1–2 年级置灰「三年级起开设」，不可点击
3. 每张科目卡保留独立年级入口（右上角「三年级 ⌄」），覆盖全局值
4. 某科单独设过年级后，全局切换时该科弹轻提示「数学科已单独设为四年级，是否跟随？」
5. 年级切换后错题本数据保留（按科 + 年级筛选展示）

**元素明细**

| # | 元素 | 规格与内容 | 数据来源 |
|---|---|---|---|
| ① | 顶部栏 | 左 App 名（15px 加粗）；右全局年级 chip「三年级 ⌄」，点击展开半屏年级弹层 | db_user_config.grades 全局值 |
| ② | 主 CTA 大卡 | 紫底满宽卡（16px 圆角）；标题「继续昨天的练习」白字 16px；摘要行紫浅字 11px：科目·样式·题量·含昨日错题数；右侧白底紫字「开始」按钮 | db_quiz_log 最近一条 + db_wrong_book 当日待重现数 |
| ③ | 激励摘要行 | 卡内底部：星星图标+火焰天数 \| 「今日还差 n 科」（今日已练科目 < 3 时显示） | db_quiz_log 聚合 |

| ⑥ | 周报摘要条 | 浅灰卡：「本周消灭错题 23 个 · 火焰 5 天」+ 右箭头；点击进周报 | weeklyReport 云函数 |
| ⑦ | TabBar | 三项：练习（当前，紫色指示条）/ 错题本 / 我的 | 静态 |

**状态**
- 老用户常态：② 显示上次科目样式；③ 有火焰数据
- 首启 0 数据态：② 变「开始第一次练习 · 3 分钟」白字；③ 隐藏；⑥ 变「完成第一次练习后生成周报」置灰；① 无已存年级时首次点开自动弹年级选择
- 弱网态：全部数据走本地缓存镜像，页面正常渲染，不露 loading 骨架

**交互规则**
- ② 点击 → 直接进练习页（跳过二级页和参数页，用上次参数 + 默认值）
- ⑤ 点击 → 学科二级页；置灰卡点击 → 轻提示 toast「英语三年级起开设」
- ① 年级 chip 切换 → 科目卡 ⑤ 即时刷新 + 各科样式摘要更新；若某科有独立年级覆盖则弹跟随确认
