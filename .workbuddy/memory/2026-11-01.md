## fix: 前端产物 config.json → config.ts（17:40，commit 7f6ae39）

- 报错：`module 'utils/config.json.js' is not defined`——小程序运行时（WAService）require 只认 js，import json 编译后运行时炸
- 平台限制：小程序包内 JSON 无加载通道（模块只认 js；image/audio 走标签；wx.request 要 CDN）；前端只能 ts/js
- 方案：构建脚本同时生成 config.ts（前端，export const CONFIG + as const）和 config.json（云函数），同一份数据两种包装
- 用户问「都当资源读不行吗」→ 解释平台无此通道；「同一份」守的是数据同源不是文件同格式
- 验证：ts/json 数据逐字节相等；模拟运行时 eval 加载 OK；TS 编译 0 错
- 教训：微信端任何 import/require 静态数据，产物一律 .ts/.js，别用 .json（resolveJsonModule 编译期能过，运行时必炸）

## fix: SWC 对象展开坑（18:08，commit f4c6c87）

- 规约：小程序端 TS 禁用对象展开；需要拷贝用 Object.keys 逐拷或显式重建
